# Plakatfonter

Alle fontene her er lisensiert under SIL Open Font License 1.1
(https://openfontlicense.org) og kan følge med i produktet.

| Fil | Font | Opphav |
|-----|------|--------|
| Geist-*.ttf | Geist | Vercel |
| anton-*.woff | Anton | The Anton Project Authors |
| archivo-black-*.woff | Archivo Black | Omnibus-Type |
| bebas-neue-*.woff | Bebas Neue | Dharma Type |
| dm-serif-display-*.woff | DM Serif Display | Colophon Foundry / Google |
| fredoka-*.woff | Fredoka | The Fredoka Project Authors |
| oswald-*.woff | Oswald | The Oswald Project Authors |

Woff-filene er `latin`-utsnittet fra Fontsource. Tegn de mangler (š, ł, ő …)
tegnes med Geist, som har full latinsk dekning — se `lib/poster/text.ts`.
